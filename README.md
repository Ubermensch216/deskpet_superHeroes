# 수퍼히어로 데스크톱 펫 (Superheroes Desktop Pet)
### 수퍼맨 · 배트맨 · 스파이더맨 · 토르 · 원더우먼 — 바탕화면을 지키는 5인의 히어로

`deskPet_Bugi`(부기) / `deskPet_Neoburi`(너부리)와 **완벽히 동일한 기능**을 갖추고, 캐릭터를 인터넷 조사를 통해 철저하게 고증한 **수퍼맨, 배트맨, 스파이더맨, 토르, 원더우먼**으로 구현한 데스크톱 펫 프로그램입니다.

외부 이미지 파일 없이 **100% C# GDI+ 벡터 그래픽 리그(`src/HeroRig*.cs`)**로 구현되어, 마스크·헤어·망토·사지·눈빛·무기(묠니르, 배트랭, 거미줄) 및 각종 시각 효과가 독립적인 관절과 물리 역학에 따라 부드럽게 움직입니다.

각 캐릭터마다 철저하게 원작 코믹스 및 미디어를 고증한 **4가지 고유 특징 행동(시그니처 기술, 총 16종)**이 탑재되어 있습니다.

---

## 🚀 빠른 시작 (실행 방법)
- 설치가 필요 없는 단일 실행 파일입니다. (.NET Framework 4.8 기본 내장, Windows 10 / 11 지원)
- `output\superheroes.exe`를 더블 클릭하여 실행합니다.
- 설정 및 기록은 `%AppData%\수퍼히어로\` 경로에 안전하게 자동 저장됩니다 (`수퍼히어로_설정.ini`, `수퍼히어로_움직임.ini`, `수퍼히어로_기록.xml` 등).

## 🎮 조작법 & 주요 기능 (Bugi / Neoburi 동일 기능)

| 조작 | 동작 설명 |
|---|---|
| **좌클릭** | 히어로별 고유 반응 (수퍼맨: 당당한 미소, 배트맨: 날카로운 안광 경계, 스파이더맨: 찌릿 놀라기/브이, 토르: 호탕한 미소, 원더우먼: 당당한 전사의 미소) |
| **마우스 드래그 & 던지기** | 살짝 놓으면 망토/웹으로 천천히 활공 착지, 빠르게 던지면 포물선 비행 후 슈퍼히어로 랜딩 착지! |
| **마우스 호버** | 커서가 다가가면 고개를 돌려 반응하거나 회피 질주 |
| **우클릭** | 풍부한 컨텍스트 메뉴 (★ 히어로 특징 행동, 동작 보기, 친구 부르기, 대화하기, 데스크 노트, 간식 주기, 설정 등) |
| **트레이 아이콘** | 더블 클릭 = 모두 숨기기 / 보이기, 우클릭 = 트레이 메뉴 |
| **숨은 반응** | 머리 위에서 마우스를 빙글빙글 돌리면 **어질어질**, 10초 안에 3번 던지면 **초스피드 비행 돌진** |

### 부가 기능 (동일 탑재)
- **벽 타기 / 천장 매달리기 / 창문 타기**: 열려있는 작업창 테두리와 화면 벽면, 천장에 거꾸로 매달려 이동
- **AI 대화 & 일기장**: Ollama 로컬 LLM 또는 클라우드 API(OpenAI/Gemini 등) 연동 대화, 히어로별 100개 이상의 상황별 오프라인 한국어 대사, 대화 일기장(`수퍼히어로_일기.txt`), 기억 관리
- **마크다운 데스크 노트**: 바탕화면 스티키 메모장, 마크다운 렌더링, 체크리스트, 알림 타이머, 히어로별 테마 컬러 지원
- **알림 펫 (AlertPet)**: 화면 구석에서 정각 알림, 점심시간 알림, 퇴근 알림, 스트레칭 휴식 타이머 제공
- **여러 히어로 동시 소환**: 우클릭 메뉴의 `[친구] -> [한 마리 더 부르기]`로 수퍼맨, 배트맨, 스파이더맨, 토르, 원더우먼을 동시에 바탕화면에 띄울 수 있습니다.

## ⭐ 5인의 히어로 고증 & 4대 특징 행동 (총 20종)

우클릭 메뉴의 **[★ 히어로 특징 행동]** 또는 **[동작 보기]**에서 언제든지 바로 감상할 수 있습니다.

| 히어로 | 상징 외형 & 고증 | ★ 특징 행동 4가지 |
|---|---|---|
| **수퍼맨**<br>*(Superman)* | • 단정한 흑발과 이마의 **'S'자 앞머리 컬**<br>• 로열 블루 수트 & 붉은 망토<br>• 가슴의 황금/붉은색 **오각형 다이아몬드 S 심볼**<br>• 황금 벨트와 클래식 붉은 부츠 | **1. 히트 비전 (Heat Vision)**: 두 눈이 붉게 타오르며 바닥으로 강렬한 고열 레이저를 발사해 지면을 녹임<br>**2. 냉기 입김 (Freeze Breath)**: 가슴 깊이 숨을 들이쉰 뒤 입으로 푸른 냉기 폭풍을 내뿜어 얼음 결정 생성<br>**3. 초음속 펀치 (Sonic Punch)**: 하늘로 솟구쳐 소닉 붐 링을 일으킨 뒤 전광석화처럼 급강하 펀치<br>**4. 셔츠 찢기 (Shirt Rip)**: 정장 셔츠를 힘차게 찢어 가슴 속 찬란한 S 심볼을 드러내며 각성 |
| **배트맨**<br>*(Batman)* | • 뾰족한 박쥐 귀 카울과 **날카로운 흰색 안광**<br>• 다크 차콜 방탄 수트 & 가슴의 검은 박쥐 엠블럼<br>• 끝이 톱니 모양(박쥐 날개)으로 재단된 검은 망토<br>• 3개 핀 건틀릿과 황금빛 **유틸리티 벨트** | **1. 배트랭 투척 (Batarang Throw)**: 벨트에서 배트랭을 꺼내 회전 투척하고 돌아온 배트랭을 완벽 캐치<br>**2. 그래플건 발사 (Grapnel Gun)**: 그래플건을 위쪽 창문으로 조준 발사해 와이어를 타고 밤하늘로 솟구침<br>**3. 연막탄 은신 (Smoke Pellet)**: 바닥에 연막탄을 터뜨려 짙은 연무 속으로 숨었다가 번뜩이는 안광과 재등장<br>**4. 가고일 응시 (Gargoyle Perch)**: 석조 가고일 위에서 망토를 거대한 박쥐 날개처럼 펼치며 도시를 감시<br>**5. 중무장 아머 슈트 (Heavy Armor)**: 장갑 부품이 날아와 찰칵 장착되고 붉은 발광 라인이 켜지며 건틀릿 블레이드·어깨 미사일·배트 수리검을 시험 사격<br>**6. 배트모빌 탑승 (Batmobile)**: 건틀릿으로 호출하면 애프터버너를 뿜으며 달려와 캐노피가 열리고, 뛰어올라 탑승해 질주<br>**7. 배트포드 사출·질주 (Batpod)**: 손상된 터미블러에서 배트포드가 사출되고 본체는 자폭, 엎드려 타고 쌍기관포를 쏘며 질주했다 복귀<br>**8. 배트윙 탑승 출격 (Batwing)**: 배트 시그널로 부른 헬리콥터형 배트윙이 회전날개 바람과 함께 내려와 윈치로 탑승, 날아갔다 망토 글라이더로 강하 |
| **스파이더맨**<br>*(Spider-Man)* | • 전신 마스크와 감정에 따라 변하는 **커다란 흰 렌즈 눈**<br>• 레드 & 블루 투톤 수트와 **전신 거미줄 격자 패턴**<br>• 가슴의 검은 거미 엠블럼<br>• 날렵하고 유연한 아크로바틱 소년 체형 | **1. 웹 스윙 (Thwip Swing)**: "THWIP!" 손가락 제스처로 거미줄을 공중에 쏘아 매달려 신나게 도심 스윙<br>**2. 스파이더 센스 (Spider-Sense)**: 머리 둘레에 찌릿찌릿 위험 감지 번개 파형이 튀며 아크로바틱 백플립 회피<br>**3. 거꾸로 매달리기 (Upside-Down Hang)**: 거미줄 한 가닥에 거꾸로 매달려 흔들거리며 손 흔들기 & 피자 냠냠<br>**4. 거미줄 네트 (Web Trap)**: 양손 웹슈터를 교차 발사해 전방에 거대한 방사형 거미줄 그물망 전개 |
| **토르**<br>*(Thor)* | • 양옆에 날개 달린 **은색 아스가르드 투구**<br>• 찰랑이는 금발 머리와 위엄 있는 금빛 턱수염<br>• 가슴에 6개의 원형 은색 플레이트가 박힌 갑옷 & 진홍빛 망토<br>• 전설의 망치 **묠니르(Mjolnir)** | **1. 묠니르 풍차 회전 (Mjolnir Whirlwind)**: 가죽 스트랩을 쥐고 묠니르를 고속 회전시켜 에너지 방어막과 돌풍 형성<br>**2. 천둥 벼락 소환 (Summon Lightning)**: 묠니르를 하늘 높이 치켜들자 하늘에서 거대한 벼락이 내리꽂히며 전신 감전<br>**3. 지면 강타 충격파 (Ground Slam)**: 도약 후 묠니르로 땅을 쾅 내리쳐 대지 균열과 함께 푸른 번개 분출<br>**4. 묠니르 투척 & 귀환 (Mjolnir Throw)**: 묠니르를 회전 투척해 표적을 강타하고 손을 뻗어 번개 궤적으로 되돌려 받음 |
| **원더우먼**<br>*(Wonder Woman)* | • 붉은 별이 박힌 **황금 티아라**와 윤기 나는 긴 흑발<br>• **황금 독수리**가 새겨진 붉은 흉갑<br>• 별무늬 푸른 스커트 & 황금 벨트(진실의 올가미)<br>• **은색 팔찌**와 흰 줄무늬 붉은 부츠 | **1. 은팔찌 방어 (Bracelets)**: 양팔을 교차해 날아오는 총알을 은팔찌로 튕겨 내며 황금빛 불꽃을 터뜨림<br>**2. 진실의 올가미 (Lasso of Truth)**: 올가미를 머리 위로 휘돌려 던져 목표를 포박하고 진실의 빛을 방출<br>**3. 검과 방패 (Sword & Shield)**: 아마존의 방패로 막고 검을 호쾌하게 두 번 휘두름<br>**4. 아마존의 비행 (Amazon Flight)**: 별빛 꼬리를 끌며 솟구쳐 날다가 사뿐히 착지 |

## 🛠️ 빌드 방법 (개발자용)

본 프로젝트는 .NET SDK에 내장된 Roslyn 컴파일러를 통해 의존성 없이 단일 실행 파일로 자동 컴파일됩니다.

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

빌드 시 `output\superheroes.exe` 파일이 생성되며, 아이콘이 없을 경우 벡터 코드로 수퍼맨 얼굴 아이콘(`assets\superheroes.ico`)을 자동 렌더링하여 exe에 포함시킵니다.

### 자가 진단 및 렌더링 검증 모드
```powershell
# 전체 기능 단위 테스트 및 시뮬레이션 검증 (selftest_result.txt 생성)
output\superheroes.exe --selftest output

# 모든 히어로의 동작 스프라이트 시트 및 애니메이션 모션 스트립 PNG 생성
output\superheroes.exe --render-test docs 1.0
```
