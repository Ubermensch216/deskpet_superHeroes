# 드래곤볼 데스크톱 펫 — 손오공 · 어린 오공 · 무천도사 · 베지터 · 피콜로

`deskPet_Bugi`(부기) / `deskPet_Neoburi`(너부리)와 **같은 기능**의 바탕화면 펫이고, 캐릭터를 드래곤볼 5인으로 바꿨습니다.
그림 파일 없이 **코드로 부위별로 그려서**(`src/DbRig*.cs`) 머리카락·표정·팔·다리·망토·꼬리·기(氣) 에너지가 따로 움직입니다.
캐릭터마다 **★ 시그니처 기술 3가지**(모두 15가지)가 있고, 설정 메뉴는 6개 분류로 새로 정리했습니다.

## 실행
`output\dragonball.exe` 를 실행하면 됩니다. 설치가 필요 없고(.NET Framework 4.8 — Windows 10/11 기본 포함) EXE 한 개로 동작합니다.
설정·기록은 `%AppData%\드래곤볼\` 에 저장됩니다(`드래곤볼_설정.ini`, `드래곤볼_움직임.ini`, `드래곤볼_기록.xml`). 다른 펫과 따로 저장되고 동시에 실행해도 됩니다.

## 사용법
| 조작 | 동작 |
|---|---|
| 클릭 | 발끈(베지터·피콜로는 💢) 또는 깜짝 놀람 → 달달 떨며 울기 → 폴짝 (설정에서 변경) |
| 끌어서 놓기 | 살짝 놓으면 기를 모아 둥실 하강(어린 오공은 근두운), 휙 던지면 날아간 뒤 내려옴 |
| 우클릭 | 간식 · ★ 시그니처 · 동작 보기 · 친구 · 빠른 설정 · 도우미 · 설정 · 종료 |
| 커서를 가까이 | 슉! 질주하며 도망 (설정에서 “따라오기”·“무시”로 변경) |
| 트레이 아이콘 | 더블클릭 = 모두 숨기기/보이기, 우클릭 = 같은 메뉴 |

숨은 반응: 머리 위에서 마우스를 한 바퀴 돌리면 **어질어질**, 친구 둘 이상일 때 커서를 4초 떼어 두면 **몰래 군무**,
같은 친구를 10초 안에 3번 던지면 **기 폭발**(금빛 오라와 번개, 변신하며 천장까지 솟구침).
벽·천장·열린 창 타기, 친밀도·포만감·꽃다발, 점심·퇴근·정각 알림, 할 일·메모·타이머, 자동 시작은 부기·너부리와 같습니다.

## ★ 시그니처 기술 (캐릭터별 3종)
시그니처가 나오면 **금빛 ★ 말풍선**(`★ 기술 이름 ★` + 외침)이 뜨고 몸 둘레로 **금빛 별**이 돌아서 일반 동작과 한눈에 구분됩니다.
메뉴·설정에서도 모두 `★` 표시가 붙습니다. 쉴 때 저절로 나오며(빈도 설정 가능), 우클릭 → ★ 시그니처 기술 또는 설정 → 캐릭터의 도감에서 바로 볼 수 있습니다.

| 캐릭터 | ★ 1 | ★ 2 | ★ 3 |
|---|---|---|---|
| **손오공** | **가메하메파** — 푸른 기를 모아 광선 발사 | **순간이동** — 이마에 두 손가락, 슉! 사라졌다 다른 곳에 나타남 | **초사이어인 변신** — 고함, 번개, 금빛 머리카락·청록 눈 |
| **어린 오공** | **근두운 타기** — 구름에 올라 둥실둥실 비행 | **여의봉 휘두르기** — 빙글 돌리다 하늘 높이 쭉 늘려 내리침 | **보름달 대원숭이** — 달을 보고 거대 원숭이로 변신, 가슴 쿵쿵 |
| **무천도사** | **원조 가메하메파** — 큰 광선 후 허리를 부여잡음 | **MAX 파워** — 근육이 부풀어 알통 포즈, 곧 쪼그라듦 | **봉마파(전기밥솥)** — 밥솥으로 기를 빨아들여 뚜껑 탁! |
| **베지터** | **빅뱅 어택** — 기탄을 날려 폭발, 팔짱 | **파이널 플래시** — 두 손으로 황금빛 광선 | **왕자의 오라** — 팔짱 낀 채 떠올라 푸른 오라 폭발 |
| **피콜로** | **마관광살포** — 이마에 두 손가락, 꼬인 광선 | **팔 늘리기** — 팔이 쭉쭉 늘어나 멀리 때림 | **명상 공중부양** — 책상다리로 떠올라 눈을 번쩍 |

## 설정 메뉴 재구성
기존엔 알림 설정 / 움직임·반응 설정 / 친구 기록·생활 설정 / 도우미 설정 창이 따로 있고, 우클릭 메뉴도 항목 14개가 한 줄로 늘어서 있었습니다.
이제 **설정창 하나**(왼쪽 분류 선택, 저장 한 번에 전체 저장)와 **계층형 메뉴**로 정리했습니다.

| 분류 | 내용 |
|---|---|
| 캐릭터 | 지금 있는 친구 목록(부르기·보내기·숨기기), 캐릭터 도감 + ★ 시그니처 미리보기, ★ 자동 재생 빈도 |
| 움직임 | 돌아다니는 곳(벽·천장·창), 쉬는 방법, 얌전 모드·위치 고정, 속도 |
| 반응 | 클릭 반응, 커서가 가까울 때(도망/따라오기/무시), 숨은 반응 |
| 생활 | 친밀도·포만감(실시간)·간식, 배고픔 설정, 숨은 반응 도감 |
| 알림 | 정각 알림(표시 방식·가장자리 빛·평일 제외), 점심·퇴근, 낮잠 |
| 화면 · 시스템 | 캐릭터 크기·진하기, 도우미 창 옵션·색, Windows 자동 시작, 설정 초기화 |

우클릭 메뉴: `♥ 친밀도` · `간식 주기` · `★ 시그니처 기술 ▶` · `동작 보기 ▶`(쉬는 모습/멈춘 몸짓/반응/이동/숨은 반응) · `친구 ▶`(부르기·보내기·숨기기·다시 부르기) · `빠른 설정 ▶`(위치 고정·얌전 모드·★ 자동 재생·친밀도 표시) · `도우미` · `설정` · `종료`.
(도우미 = 할 일·메모·타이머는 설정이 아니라 도구라서 별도 창으로 두고, 그 창의 옵션만 설정 → 화면·시스템으로 옮겼습니다.)

## 빌드
```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```
.NET SDK 의 Roslyn 으로 .NET Framework 4.8 대상 EXE 를 만듭니다(`output\dragonball.exe`). 아이콘(`assets\dragonball.ico`)이 없으면 손오공 얼굴을 그려 자동으로 만듭니다.

## 점검 모드 (개발용)
```
dragonball.exe --selftest <폴더>             설정·기록 저장, 친밀도 계산, 상태 전이 점검 (selftest_result.txt)
dragonball.exe --ui-test  <폴더>             모든 창·실제 마우스 입력 점검, 화면 캡처 (마우스를 움직이니 주의)
dragonball.exe --render-test <폴더> [배율]    캐릭터별 모든 모습의 시트(sheet_*.png)와 ★ 시그니처 포함 연속 컷(motion_*.png)
```

## 파일 구성 (`src/`)
`DbRig.cs`·`DbRigHead.cs`·`DbRigFx.cs` 5인 그리기(몸통·팔 IK·다리·머리카락·표정·오라·기 구슬·광선·근두운·여의봉) · `RigCommon.cs` 자세(Pose)와 도구 · `PetSignature.cs` ★ 시그니처 15종 · `PetPersona.cs` 캐릭터별 몸짓 · `PetPoses.cs` 상태별 자세 · `PetRender.cs` 자세 → 비트맵(말풍선·★ 장식·보름달) · `FormsSettings.cs` 통합 설정창 · `App.cs` 메뉴·트레이 · 나머지는 부기·너부리와 같은 상태기계·창 코드.

드래곤볼 캐릭터의 저작권은 각 권리자(토리야마 아키라 · 슈에이샤 · 도에이 애니메이션)에게 있습니다. 이 프로젝트는 개인용 팬 프로젝트이며, 실행 파일에는 이미지 파일이 들어 있지 않고 코드로 새로 그린 그림만 씁니다.
